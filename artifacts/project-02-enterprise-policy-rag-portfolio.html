01

해결한 문제

권한이 없는 문서가 검색되거나 근거가 부족한 답변이 생성되는 문제

기업 내부 정책 RAG는 검색 품질만으로 부족합니다. 사용자가 볼 수 없는 문서가 검색 후보에 섞이지 않아야 하고, 답변에는 근거가 남아야 하며, 근거가 부족한 경우 거절 응답을 반환해야 합니다.

02

핵심 설계 판단

01

Authorization first

답변 생성 전에 접근 가능한 chunk만 검색 후보로 제한

02

Evidence policy

citation이 없으면 refusal을 반환하고 LLM 호출을 생략

03

Replaceable boundary

provider와 repository를 분리해 기본·외부 경로를 교체

04

검증 결과

  • 권한 검색 테스트에서 문서 5개 중 허용 범위 3개만 반환하고 다른 workspace 결과는 0건으로 고정합니다.
  • 근거가 없으면 answer=null, citations=[]를 반환하고 provider 호출을 생략합니다.
  • 권한 밖 보안 문서가 검색 결과와 citation에 포함되지 않는 API 시나리오를 검증합니다.
OUTCOME

권한 밖 문서를 검색·인용에서 차단하고, 근거가 없으면 provider 호출 없이 거절 응답을 반환합니다.
