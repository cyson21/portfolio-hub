StockRush

분산 정합성
Kafka · Saga · Transactional Outbox
문제

주문·결제·재고가 분리된 흐름에서 중복 이벤트, 늦은 결제 승인, 발행 재시도로 주문 상태와 Outbox가 어긋날 수 있었습니다.

보호

Saga 보상 흐름과 Transactional Outbox를 구성하고, 소비자 멱등 처리와 취소·완료 상태의 후속 변경 차단을 보호 규칙으로 두었습니다.

검증

중복 이벤트를 2회 받아도 Outbox 1건만 유지되고 취소 후 늦은 승인이 무시됨을 확인했습니다. 재시도 4회 상태의 다음 발행 실패에서 횟수 5·FAILED 전환을 통합 테스트로 검증했습니다.

Member Event Consistency

동시성·정합성
PostgreSQL · Redis · RabbitMQ
문제

동시 요청에서 최초 보상이 중복 지급되거나 쿠폰이 정원을 초과해 발급되고 포인트 잔액이 음수가 될 수 있었습니다.

보호

PostgreSQL 제약과 조건부 갱신을 최종 보호 규칙으로 두고, Redis 잠금과 RabbitMQ 단일 소비자 처리의 역할을 분리했습니다.

검증

PostgreSQL Testcontainers에서 최초 보상 동시 요청 8건 중 1건만 반영됐고, 60포인트 차감 2건은 1건 성공·1건 거절·잔액 40으로 수렴했습니다. RabbitMQ Testcontainers에서는 정원 3건에 발급 3건·거절 5건을 검증했습니다.

Enterprise Policy RAG

권한 기반 검색
FastAPI · PostgreSQL · RAG
문제

권한 밖 문서가 검색 후보에 섞이거나 근거 문서 없이 LLM을 호출하면 보안 경계와 답변 신뢰도가 무너질 수 있었습니다.

보호

workspace·소유자·공개 범위·부서 조건을 검색 전에 적용하고, 허용된 근거가 0건이면 provider 호출 없이 거절 응답을 반환하도록 경계를 고정했습니다.

검증

메모리 저장소 회귀 테스트에서 다른 workspace·부서·비공개 문서가 검색 결과에서 제외되고, 근거 0건에서 provider 호출 0회와 insufficient_evidence 응답이 유지됨을 확인했습니다.
